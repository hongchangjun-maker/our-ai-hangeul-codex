# 전체 사용자 동선 시뮬레이션 보고서

검증일: 2026-08-25
대상: 우리의 AI 한글 운영 배포본 및 동일 소스의 로컬 프로덕션 빌드

## 검증한 동선

- 시작 화면, 네 가지 템플릿, 최근 문서 열기, 저장 후 홈 이동과 재진입
- 한글·영문·숫자 연속 입력, 반복 Backspace, 전체 선택, 굵게와 표 삽입
- 한 쪽/두 쪽 보기, 페이지 추가, 표준 용지와 여백 가이드
- Markdown 실제 가져오기, HWPX 실제 생성 완료, DOCX·HWPX·ODT 왕복 단위 검증
- 찾기·바꾸기, 한국어 기본 교정, 머리말·꼬리말·쪽 번호
- 클라우드 버전 조회, AI 미연결 상태의 정직한 차단, 콘솔 오류 확인
- 1920×1080 기준 데스크톱과 390×844 모바일 레이아웃

## 발견하고 수정한 결함

1. 이전 문서의 선택 범위가 새 문서·가져온 문서에 남아 첫 삽입이 새 본문 전체를 교체할 수 있던 문제
2. 편집 후 다른 템플릿을 만들 때 이름과 용지만 바뀌고 이전 본문이 남을 수 있던 편집기 재부착 경쟁 조건
3. 새 문서·가져온 문서에서도 이전 선택 글자 수가 상태 표시줄에 남던 문제
4. 최근 문서를 열기만 해도 변경됨으로 표시되고 최근 문서 시간이 다시 갱신되던 저장 상태 문제
5. 홈 이동 직전 편집기 버퍼가 즉시 저장되지 않아 잘못된 복구 알림이 남을 수 있던 문제
6. 서식·글꼴 토글이 활성 상태를 보조기기에 전달하지 않던 접근성 문제
7. 대화상자를 Esc로 닫을 수 없고 Tab 포커스가 대화상자 밖으로 빠질 수 있던 키보드 사용성 문제
8. 클라우드판의 쪽 수가 더 적을 때 현재 쪽 인덱스가 범위를 벗어날 수 있던 문제
9. 브라우저 탭 아이콘 메타데이터가 없어 기본 아이콘 요청이 404로 남던 문제

## 자동 검증

- TypeScript 정적 검사
- 12개 테스트 파일, 48개 회귀 테스트
- 모듈 소유권·의존 경계·파일 책임 크기 검사
- ESLint
- Vinext 프로덕션 빌드
- 운영 의존성 취약점 검사: 0건

## 운영상 남은 외부 제한

- OpenAI는 관리자 서버 설정 전까지 `OPENAI_NOT_CONNECTED`로 차단된다.
- D1 문서 버전 동기화는 동작하지만 R2 첨부 동기화와 Durable Objects 실시간 커서는 해당 Cloudflare 리소스 연결 전까지 완전 활성화되지 않는다.
- 매우 복잡한 외부 DOCX/HWPX의 프로그램별 렌더링 차이는 남을 수 있으므로 원본 보관과 PDF 비교가 필요하다.
- 실제 프린터 드라이버별 종이 급지·색상 결과는 브라우저 인쇄 미리보기 이후 사용자의 장치에서 최종 확인해야 한다.
